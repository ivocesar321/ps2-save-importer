# Changelog

## 0.1.0 - 2026-06-13

- Ported the original mymc Python 2 codebase to Python 3.
- Added a local FastAPI web interface.
- Added PCSX2 local-card discovery and safe save-back backups on macOS.
- Added PS2 `.psv` import support.
- Made newly created cards use ECC by default for PCSX2 compatibility.
- Added CI, tests, and open-source project documentation.
