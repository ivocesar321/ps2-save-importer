# Avisos de componentes de terceiros

## MyMC — PS2 Memory Card Manager

O PS2 Save Importer incorpora `App/mymc.exe`, ferramenta baseada no projeto MyMC incluído em `source/ps2-memory-card-manager-main`.

O código-fonte desse componente contém uma licença **The Unlicense**, disponível em:

- `source/ps2-memory-card-manager-main/LICENSE`
- https://unlicense.org/

O MyMC é um componente de terceiros. Sua autoria e licença permanecem distintas das do PS2 Save Importer.
